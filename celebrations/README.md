# Celebrations

A record of OAN's critical wins: launches, successful integrations, major partnerships, adoption milestones, and other achievements worth recognizing. Add a new page for each win and keep entries ordered newest first in the table of contents.

Use the [Critical Win Template](critical-win-template.md) for every new celebration. Name files using the win date and a short description, for example `2026-07-31-first-state-integration.md`.
